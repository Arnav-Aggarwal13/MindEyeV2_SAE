(x + 1) / 2, so the model was trained against targets computed from images squeezed into [0.5, 1] ("as_trained").
Is the base run's prior_out closer to that target than to the one from a proper [0, 1] input (images fed as 2x - 1, "pm1")?

INTERPRETATION
The as-trained target is closer to prior_out for most images, and the difference is statistically clear, but it is small (about 0.01
in cosine). Retrieval accuracy is essentially identical for both targets. This agrees with reading Train.ipynb (the as-trained
preprocessing defines the target) but the empirical test alone would not settle it, because the two targets are 0.88 similar to each other.
Absolute closeness of prior_out to either target is modest (flat cosine ~0.42, relative squared error > 1), probably because prior_out is a
single noisy diffusion sample. Not independently verified.
