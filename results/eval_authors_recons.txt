TESTS NOT RUN, AND WHY
- Retrieval (forward / backward image<->brain): needs *_all_clipvoxels.pt, which the authors do not publish.
- Caption metrics (METEOR, ROUGE, MiniLM, CLIP-B, CLIP-L text similarity): need *_all_predcaptions.pt, not published.
- UMAP plots: need prior_out / backbone / clipvoxels files, not published.
- Enhanced-recon blending (recons*0.75 + blurry*0.25): not applicable; we evaluate regular recons only and the authors' blurry recons are not published.
These can be run on our own base-run outputs, which contain clipvoxels, captions and prior_out.

NOTES
1. SSIM: the notebook calls structural_similarity(..., multichannel=True), an argument removed in scikit-image >= 0.21 (we have 0.22).
   The two reported values differ a lot (0.410 vs 0.333). I could not run the old scikit-image to confirm which one the notebook
   actually computed. Indirect evidence: the notebook's saved output for the authors' ENHANCED recons shows SSIM 0.439, closer to
   the "SSIM" variant than to SSIM_2d. Treat "SSIM" as the number comparable to published values and SSIM_2d as the standard definition.
2. Reference point (not a like-for-like comparison): the outputs saved inside the upstream notebook are for the authors' ENHANCED recons:
   PixCorr 0.374, SSIM 0.439, AlexNet(2) 0.9791, AlexNet(5) 0.9911, InceptionV3 0.9600, CLIP 0.9369, EffNet-B 0.6075, SwAV 0.3363.
   Our numbers for the regular recons are lower on PixCorr and SSIM (as expected when the SDXL refinement and blurry blending are absent)
   and similar elsewhere (higher on AlexNet(5), InceptionV3, CLIP; slightly lower on AlexNet(2)). I have not checked the paper's table
   for the regular-recon numbers.
3. The next fidelity check is to run this same script on our own base-run recons (base/base_all_recons.pt) and compare them with these
   numbers. Differences are expected from sampling noise (see the GPU-dependent random-number issue noted earlier).
4. No confidence intervals are given here; per-image values for every metric are in per_image.npz so paired comparisons can be made.
